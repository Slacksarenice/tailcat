tailcat

This is an experimental demo of tailcat in the browser. Browsers can't open the UDP sockets that tailcat's direct peer-to-peer connections use, so its traffic is relayed through DERP servers, unless both sides are this page with the WebRTC option below on: then it moves to a direct WebRTC connection between the browsers when one can be made, falling back to DERP if not (issue #4).
